# Internal validator dispatched by track loaders

Internal validator dispatched by track loaders

## Usage

``` r
.validateTrackReference(
  session,
  id,
  trackName,
  target,
  validateReference = TRUE
)
```

## Arguments

- session:

  Shiny session or NULL

- id:

  Widget element ID

- trackName:

  Display name of track

- target:

  Track file path or data object

- validateReference:

  Logical, whether validation is enabled
