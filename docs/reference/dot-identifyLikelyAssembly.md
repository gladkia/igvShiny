# Infer the likely assembly of a set of contigs from lengths or metadata

Infer the likely assembly of a set of contigs from lengths or metadata

## Usage

``` r
.identifyLikelyAssembly(contigs, assemblyStr = NULL)
```

## Arguments

- contigs:

  Named integer vector of contig lengths

- assemblyStr:

  Optional string from header

## Value

String describing likely assembly or NULL
