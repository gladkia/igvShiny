# Extract contig and coordinate information from a BED data.frame or file

Extract contig and coordinate information from a BED data.frame or file

## Usage

``` r
.extractBedContigs(tbl)
```

## Arguments

- tbl:

  A data.frame with chr/chrom, start, end columns, or file path

## Value

List with contigs (named integer vector) and maxCoords (named integer
vector)
