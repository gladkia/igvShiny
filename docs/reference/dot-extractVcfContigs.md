# Extract contig information from a VCF object or file

Extract contig information from a VCF object or file

## Usage

``` r
.extractVcfContigs(vcfDataOrFile)
```

## Arguments

- vcfDataOrFile:

  A VariantAnnotation VCF object, or a path to a .vcf / .vcf.gz file

## Value

List with contigs (named integer vector) and assembly (string or NULL)
